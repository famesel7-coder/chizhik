# Типовые паттерны слайдов Чижика

## 1. Hero cover

Большой заголовок слева, 3D-объект справа. Жёлтый фон, маскот в действии.
Подходит для открытия блока.

## 2. Ambition / metric cards

Светлый фон, крупные жёлтые карточки, большие цифры, маскот как эмоциональная сцена.
Использовать для KPI, целей, амбиций.

## 3. Targets table

Три вертикальные зоны: факт / прогноз / цель. Чёрный, молочный, жёлтый.
Подходит для сравнения 2025 / 2026 / 2028.

## 4. Process optimization

Торн-бумага / чёрная нижняя полоса, крупные числа, маскот выглядывает из-за панели.
Подходит для экономии времени, улучшения процессов.

## 5. Product ownership

Жёлтая сцена с упаковкой продукта в центре, вокруг этапы/принципы.
Подходит для качества, СТМ, продукта, упаковки.

## 6. App / widget backlog

Яркий жёлтый фон, смартфоны, карточки интерфейса, маскот как герой интерфейсного улучшения.
Подходит для цифровых продуктов.

## 7. Analytics split

Левая чёрная зона с объектом, правая светлая зона с графиками.
Подходит для данных, пилотов, результатов, сравнения групп.

## 8. Number one hero

Гигантская цифра или `№1`, маскот маленький рядом для масштаба.
Подходит для лидерства, достижений, рейтингов.

# Figma rules для слайдов Чижика

## Формат

- Основной фрейм: `1920 × 1080`.
- Все текстовые элементы — редактируемый `TEXT`.
- Fact не переводить в кривые.
- SVG-графики импортировать так, чтобы текст оставался текстом.

## Организация файла

- Один слайд = один основной фрейм.
- Названия фреймов делать понятными: `01_Hero`, `02_KPI`, `03_Analytics` и т.д.
- Черновые варианты держать на отдельной странице, а не рядом с финальными фреймами.
- Референсы и заметки выносить в `QA / reference` вне экспортной области.

## Шрифты

Использовать семейство `Fact`:
- `Compressed Extra Bold`
- `Compressed Bold`
- `Condensed Extra Bold`
- `Condensed Bold`
- `Condensed Medium`
- `Medium`
- `Bold`

Если Fact недоступен в Figma, сначала загрузить шрифты в аккаунт/организацию Figma. Не использовать случайный fallback.

## Слои

Рекомендуемая структура:
- `BG`
- `TYPE / headline`
- `TYPE / captions`
- `DATA / charts`
- `3D / mascot`
- `3D / retail objects`
- `MARKER / pink notes`
- `TEXTURE / grain`
- `QA / reference` — только вне финального фрейма

## Компоненты и стили

- Повторяющиеся карточки и плашки собирать как компоненты.
- Цвета держать в виде локальных стилей или переменных, чтобы не плодить почти одинаковые оттенки.
- Для графиков использовать единый набор текстовых стилей: headline, metric, caption, footnote.
- Розовый маркер использовать поверх основного слоя, а не запекать в картинку вместе с фоном.

## Экспорт

- Для презентации: PNG 1920×1080.
- Для редактируемых графиков: SVG с текстом.
- Для сложных 3D/маскота: PNG с прозрачным фоном.

## Проверка перед экспортом

- Проверить, что весь текст редактируемый.
- Убедиться, что ключевые числа читаются без приближения.
- Проверить, что маскот не перекрывает важные данные.
- Удалить или скрыть технические слои перед финальным экспортом.

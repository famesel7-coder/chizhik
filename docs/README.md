# Документация Чижика

Этот каталог хранит основную документацию по визуальному стилю и правилам сборки материалов.

## Содержание

- `CHIZHIK_STYLE_GUIDE.md` — визуальный стиль, палитра, типографика, принципы композиции.
- `FIGMA_RULES.md` — правила подготовки, структуры слоёв и экспорта в Figma.
- `SLIDE_PATTERNS.md` — типовые сценарии и композиции слайдов.
- `REFERENCE_SLIDES_INDEX.md` — список референсных слайдов и их роли.
- `ASSET_PROMPTS.md` — промпты и ограничения для генерации ассетов.
- `REPO_STATUS.md` — текущее состояние репозитория и рекомендации по ведению.

## Как пользоваться

1. Сначала сверяться со style guide.
2. Затем выбирать подходящий slide pattern.
3. После этого собирать макет по Figma rules.
4. Новые ассеты и графики сохранять в `assets/`.

# Промпты/ТЗ для генерации ассетов в стиле Чижика

## Маскот

Круглый пушистый чёрный птенец Чижик, большие карие глянцевые глаза, маленький чёрный клюв, короткие лапки, небольшой хохолок, 3D soft plush look, friendly, curious, joyful, Chizhik retail brand style, clean lighting, high quality.

## Маскот + действие

Добавлять конкретное действие:
- бежит по кассовой ленте;
- держит жёлтую корзинку;
- выглядывает из-за чёрной torn-paper стенки;
- летит на воздушном шаре;
- едет на скейте;
- показывает крылом на метрику;
- сидит рядом с продуктовой упаковкой.

## 3D-объекты

Стиль: matte 3D, tactile materials, yellow/black/cream palette, retail supermarket context, clean commercial render, no random glossy sci-fi.

Объекты:
- касса и кассовая лента;
- продуктовая корзина;
- полка с продуктами;
- упаковка private label;
- конвейер качества;
- смартфоны с виджетами;
- таблички/плашки/стикеры.

## Фон

- `#FFD900` для яркого hero;
- `#FCF6ED` для аналитики и графиков;
- `#111111` для контраста;
- добавить лёгкую печатную фактуру, но не грязь.

## Чего избегать в генерации

- Случайного sci-fi или cyberpunk-визуала.
- Фотореалистичных людей, если задача про маскота или объект.
- Слишком глянцевого пластика без тактильности.
- Холодных синих и фиолетовых схем вместо фирменной палитры.
- Сложного шумного фона, который мешает типографике.

## Именование файлов

- Маскот: `mascot_<action>_<variant>.png`
- Объекты: `object_<scene>_<variant>.png`
- Графики: `chart_<topic>_<version>.svg`

# Чижик — стиль презентаций

Рабочий репозиторий для фиксации визуального стиля, правил сборки и вспомогательных материалов для презентаций Чижика.

## Что внутри

- `docs/README.md` — быстрая навигация по документации.
- `docs/CHIZHIK_STYLE_GUIDE.md` — основной стиль-гайд по визуальному языку.
- `docs/FIGMA_RULES.md` — правила сборки и экспорта макетов в Figma.
- `docs/SLIDE_PATTERNS.md` — типовые композиции и сценарии слайдов.
- `docs/REFERENCE_SLIDES_INDEX.md` — индекс референсных слайдов.
- `docs/ASSET_PROMPTS.md` — промпты и ТЗ для генерации ассетов.
- `docs/REPO_STATUS.md` — текущее состояние и правила ведения репозитория.
- `assets/svg/` — место для редактируемых графиков и схем.
- `assets/images/` — место для PNG, JPG, WebP и прозрачных ассетов.
- `chizhik_style_repo_package.zip` — архивная упаковка первой версии материалов.

## Быстрый старт

1. Начать с `docs/CHIZHIK_STYLE_GUIDE.md`.
2. Для сборки слайдов использовать `docs/FIGMA_RULES.md` и `docs/SLIDE_PATTERNS.md`.
3. Для генерации новых объектов и маскота брать формулировки из `docs/ASSET_PROMPTS.md`.
4. Складывать новые редактируемые материалы в `assets/`, а не в корень репозитория.

## Важно

- Репозиторий публичный.
- Не хранить здесь приватные ссылки, чувствительные данные и внутренние пароли.
- Если стиль обновляется после новых референсов, сначала править документацию, потом собирать новые слайды.

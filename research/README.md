# Research

Публичная база знаний по внешним брендам, референсам и открытым исследованиям.

## Что внутри

- `apelsin/README.md` — краткая выжимка по бренду «Апельсин».
- `apelsin/brandbook_extracted.md` — извлечённый брендбук на основе открытых источников.
- `apelsin/sources.md` — источники, даты и пометки по верификации.

## Принципы

- Используем только открытые источники.
- Отделяем прямые факты от аналитических выводов.
- Фиксируем даты публикаций и актуальности, если они доступны.
- Не складываем сюда закрытые материалы, приватные ссылки и внутренние брендбуки.

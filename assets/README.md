# Assets

Каталог для рабочих визуальных материалов, которые используются при сборке слайдов.

## Структура

- `images/` — PNG, JPG, WebP, превью, рендеры маскота и 3D-объектов.
- `svg/` — редактируемые графики, диаграммы и векторные элементы.

## Правила

- Не складывать новые рабочие ассеты в корень репозитория.
- Для графиков по возможности хранить редактируемую SVG-версию.
- Имена файлов делать осмысленными: `chart_sales_q3.svg`, `mascot_skate_v1.png`.
